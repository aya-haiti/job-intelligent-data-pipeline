        Pipeline de données

        Architecture du projet.

        1. Extraction — scrapers Rekrute (Maroc), API France Travail, API Adzuna, dataset Kaggle.
        2. Stockage brut — MinIO (S3) dans la stack Docker.
        3. Orchestration — DAG Apache Airflow : extract → transform → load.
        4. Data Warehouse — PostgreSQL en schéma en étoile (fact_offres + 5 dimensions).
        5. NLP — extraction de compétences par taxonomie, recommandation TF-IDF + similarité cosinus, lecture de CV PDF/DOCX.
        6. Interface — Flask + ce tableau de bord. En production les offres sont lues depuis Postgres (Neon).
