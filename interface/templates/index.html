Données & méthode

Pipeline

  1. Collecte — API France Travail, API Adzuna, scraping Rekrute (Maroc), dataset Kaggle « LinkedIn Data Jobs » (janvier 2024).
  2. Orchestration — DAG Apache Airflow (extract → transform → load), stockage brut MinIO.
  3. Transformation — schéma commun ; descriptions complètes, URL d'origine et salaire conservés quand la source les fournit ; extraction des compétences par taxonomie.
  4. Entrepôt — PostgreSQL en schéma en étoile ; l'interface lit une table aplatie jobs_clean.

Calcul du score

Votre texte (CV ou profil) et chaque offre (titre ×3 + description) sont transformés en vecteurs TF-IDF (5 000 termes, unigrammes et bigrammes). Le score est la similarité cosinus entre les deux vecteurs, de 0 à 100 %. La couverture indique la part des compétences de l'offre présentes dans votre profil.
